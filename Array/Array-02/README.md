
# Array-02

This repository contains Java array programming exercises covering array traversal, calculations, shifting, swapping, reversing, digit manipulation, and problem-solving.

## Array Case 1: Forward and Backward Display

Create an array of integers and display its elements in forward and backward order.

**Example Input:**
```text
Array = [10, 20, 30, 40, 50]
```

**Expected Output:**
```text
Forward: 10 20 30 40 50
Backward: 50 40 30 20 10
```

## Array Case 27: Case Study - Divisible by 4 and/or 5

Rules:
- Black number: Divisible by 4; replace with `-1`.
- White number: Divisible by 5; replace with `-2`.
- Grey number: Divisible by both 4 and 5; replace with `-3`.

**Example Input:**
```text
Input: [10, 14, 24, 12, 18, 26, 20, 23, 22, 15, 26]
```

**Expected Output:**
```text
Output: [-2, 14, -1, -1, 18, 26, -3, 23, 22, -2, 26]
```

## Array Case 28: Case Study - Divisible by 6 and/or Contains 6

Rules:
- Black number: Divisible by 6; replace with `-1`.
- White number: Contains digit `6`; replace with `-2`.
- Grey number: Both divisible by 6 and contains digit `6`; replace with `-3`.

**Example Input:**
```text
Input: [15, 23, 18, 26, 72, 36, 49, 38, 60, 17, 22, 46]
```

**Expected Output:**
```text
Output: [15, 23, -1, -2, -1, -3, 49, 38, -3, 17, 22, -2]
```

## Array Case 29: Find Adjacent Values

Calculate the absolute difference between each element and its next adjacent element. Store the differences in a new array.

**Example Input:**
```text
Array = [15, 23, 18, 26, 72, 36, 49, 38, 60, 17, 22, 46]
```

**Expected Output:**
```text
Differences = [8, 5, 8, 46, 36, 13, 11, 22, 43, 5, 24]
```
